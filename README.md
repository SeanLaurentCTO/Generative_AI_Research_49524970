# AI Research

Mixed-methods research repository containing qualitative and quantitative data.

## Structure

- `01_research_design`: proposal and research instruments
- `02_literature`: reference publications
- `03_data`: raw and processed qualitative and quantitative data
- `04_analysis`: analysis scripts and generated figures
- `05_outputs`: manuscript and publication-ready outputs
- `90_archive`: duplicate, unrelated, invalid, and placeholder files

## File naming

Files use lowercase `snake_case`. Interview transcripts use anonymous participant IDs such as `p01`; participant names should not appear in filenames. Raw data must remain unchanged, while cleaned data belongs in a `processed` directory.
